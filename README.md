# Mayur Tayde — Portfolio

A responsive, single-page AI engineer portfolio built with plain HTML, CSS, and JavaScript. The hero uses Mayur’s supplied portrait at `images/mayur-tayde.jpg`.

## Preview locally

Open `index.html` in a browser. The page uses Google Fonts when online and falls back to system fonts when offline.

## Publish

Upload the contents of this folder to any static host, such as GitHub Pages, Netlify, or Vercel. For GitHub Pages, create a repository, add these files to the root, then enable Pages in the repository settings.

## Before publishing

- Confirm the supplied education, skills, internship, and content-writing details.
- Project cards link to the three public GitHub repositories and summarize their README files. The LinkedIn link is included; its publicly indexed activity did not clearly identify additional projects authored by Mayur.
- Add an email address or contact form if you want direct email contact.

The LinkedIn and GitHub buttons use the URLs provided by Mayur. Project cards link to CampusMatch, Smart-Group-AI-Analyzer, and sentiment-analysis-app. No unverified repository statistics or endorsements are displayed.
